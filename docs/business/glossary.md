# Glossary

Words the studios use, and what they mean in the app. The full training-method glossary is in `docs/msf-academy/Academy/Academy 1 - Introduction/Academy - Intro 2 - Glossary.txt`.

## People and places

| Term | Meaning |
| --- | --- |
| Life Transformer | A trainer |
| Head Trainer | Runs a studio's floor and team, the same tier as a studio leader. Its own label in the app since Sep 27 2026 (it read "Studio Leader" before) |
| Studio Leader | Runs a studio; may or may not train clients |
| Franchise Owner | Owns one or more studios |
| Home studio | Where a client is billed and mainly trains |
| Cross-train | A client approved to train at another studio |
| Snowbird | A client who spends part of the year away (usually winter) and comes back; an away event, not a lost client |

## Packages and renewals

| Term | Meaning |
| --- | --- |
| The Trial / Committed / Life Transformed | The 6-, 12- and 18-month packages (48, 96, 144 sessions) |
| Prepay | Paying the whole package up front at a lower rate per session |
| Auto-renew / charge date | When a package's payments finish and the next package starts billing |
| Banked sessions | Sessions a client still has when their payments finish; they never expire |
| Renewal conversation | The talk about continuing, started around 10 sessions before the end |
| PIF | Paid in full: a package prepaid in one go, shown in Mindbody as one pricing option ("144 PIF") |
| Session Comp | Complimentary sessions, their own pricing option; they count toward sessions left but aren't a package |
| Renewal cycle | One package term, from start to renewal or loss. Keyed by the Mindbody contract (or the PIF pricing option) |
| Will bank / will run out | Billing ends with sessions still unused / sessions run out well before billing ends |
| Lapsed | Past the studio's lost rule with no new package: the win-back list |
| Renewal on the books | The next package already signed in Mindbody while the current one runs: the client has renewed |
| Outcome | How a package ended: renewed, upgraded, downgraded, pay-as-you-go or lost |
| Renewal Brief | The leader's one-screen preparation for a client's renewal conversation, health first |

## Training method

| Term | Meaning |
| --- | --- |
| Continuous tension | The MSF protocol: a slow, smooth pace with carefully controlled changes of direction — no pause or acceleration between lowering and lifting — for safety and sustained muscle tension |
| Single set | One set per exercise, taken to or close to muscular failure; the quality of the effort is what counts |
| TUT | Time under tension — how long the set lasted |
| TSC | Timed Static Contraction: pushing against a movement arm locked in place — effort with no movement and no load held. The most conservative option, used around pain, injury or a return from surgery (with medical clearance) |
| SH | Static Hold: holding a load still. Easier to progress than a TSC, but less conservative |
| Rep quality | How a set was performed: Max Strength (protocol done perfectly), Completed, or needs improvement |
| Kaizen | "There is always room for improvement." The red kaizen mark on a set means the form needs work — never "you did badly" |
| The 4 P's | Posture, Path, Pace, Purpose — the four things trainers coach |
| Machine settings ("G9 S8") | Shorthand for a client's setup: Gap 9, Seat 8. Machines have up to five settings |

## Screens and features

| Term | Meaning |
| --- | --- |
| Hub | The studio's shared screen: today's shift, clients waiting, the board, the playbook |
| Journey Grid | A client's machine-by-session history, and the live session view |
| Now bar | The fixed bar in a live session showing the current machine and what's next |
| Briefing | The pre-session screen, and only that: check-in, critical notes, plan |
| Wrap-up | The post-session screen, walking the client out: today's sets, the journey, what's next, the Profile note and the Pulse. "Briefing is strictly pre-session while wrap up is post-session" (AJ, Sep 27 2026). Called "the post session briefing" in conversation before it had a name |
| Note for the next trainer | The note box in the End Session dialog. It files as a Heads up, so it shows on the next trainer's briefing for three weeks. It comes back in the Wrap-up's To-file tray so it can be filed to the profile too, and it is never discarded there (filing keeps it on the briefing). Was "Wrap-up note" until Sep 27 2026 |
| Profile note | The Wrap-up's own note. At Note loudness it stays on the client's profile and never reaches the briefing; Heads up or Critical sends it there too. Was "the closing note" until Sep 27 2026 |
| Kaizen Roster | A trainer's running list of clients they are keeping an eye on, each with a reason |
| Past sessions | The button on a client's Hub card that opens their Activity Archive → Sessions. Was "History" until Sep 27 2026 |
| Just now | The line on Relay's Now Bar saying what teammates just did, with the kudos heart. Was labelled "Pulse" until Sep 27 2026; Pulse is only the living assessment |
| Standing week | A trainer's usual week at a studio: when they take clients (the **blocks**) and their **regulars**. The trainer proposes it on My Profile, under "When I usually take clients"; a studio leader agrees it on My Studio → Team (Sep 27 2026) |
| Block | A stretch of a weekday when a trainer usually takes clients, on their standing week. Up to three a day (since the Openings round, Sep 27 2026), with the breaks left out, because Openings reads a half-hour inside a block with nothing booked as room. A day with none reads "Doesn't take clients" |
| Regular | A client a trainer sees at the same time each week ("Judy, Monday 8:00"). Booked by the front desk in Mindbody as a recurring appointment; Journey only checks the bookings against the agreed week |
| Free slot | An agreed regular's time this week that the regular isn't booked for — she's away, or booked another day — so the trainer has the time free and the studio can fill it. Never counted on a day the trainer is away. Since the Openings round Team counts them in one line ("3 free slots in the next 7 days · See them on Openings.") and Openings → Next 7 days lists each one ("A regular isn't booked for it") |
| Away | The days a trainer is away from a studio: a range of studio days, both ends included, with an optional note. The trainer sets it on My Profile under My standing week (even with nothing proposed), or a leader in Team's Review; it needs no agreement. The week check leaves those days unchecked (no open slot, no move, no Free slot), and Team says once "Sam is away Mon, Sep 28 – Wed, Sep 30." Journey's own record, never sent to Mindbody; up to six ranges still to come (Sep 27 2026) |
| The studio rotation | Some studios open a "{studio} Rotation" in Mindbody on a slow day (often a Saturday) instead of each trainer's own bookings: clients book the rotation, and whoever works that day moves those sessions to themselves. It varies by studio and by week, and the app needs no rule for it: "not something that really we need to be working on the app. It's just something I want to give you context on" (AJ, Sep 27 2026). A regular's rotation booking at her usual time counts as usual: never moved, taken or a Free slot |
| Openings | The My Studio section, since Sep 27 2026, for when the studio is usually busy (The usual week), what opened up (Next 7 days), and what to offer a client for good (A new regular time), with Who's usually in beside them. Read only: it books nothing and pings nobody, and every offer ends "Check it in Mindbody before you promise it. Journey doesn't book." |
| The usual week | Openings' grid of half-hours, Monday to Saturday, each with its word: **Always full** (full in every judged week, at least 6), **Usually full** (a hot spot: 3 in every 4), **Usually has room** (a cold spot), **Mixed**, or **Usually N booked** when room can't be judged yet. Built each Sunday from the last eight weeks; it needs four weeks counted before it says anything |
| Counted | A past day Openings counts: Journey read its bookings in full from Mindbody (on the day before, the day, or after) and the studio was open (at least a quarter of that weekday's usual bookings). A day that isn't counted is left out, and the time's sheet says why |
| Judged | A counted day where everyone with a booking is known: every trainer booked had an agreed standing week in force, and no booking was one Journey couldn't place with a trainer. Only a judged day says full, room or nobody in; otherwise it says how many were booked |
| Mark (on a time) | A person's word on a time in the grid's own words, **Always full** or **Usually has room**, with an optional note. Anyone who works at the studio sets, changes or removes one, as themselves; it sits beside the numbers, never in place of them, and after 60 days asks "Still true?" |
| Who's usually in | Openings' list of everyone who works at the studio, in name order, each with their agreed standing week read only, and their days away. Where a colleague's week can be seen, since another trainer's profile can't be opened |
| Times with room | The door on the Wrap-up's Next card and the sheet it opens: the times with room this week and most weeks, for the client at the desk. Times only, never a name, so it is safe to turn the iPad to the client |
| Your week | On your own My Profile: clients trained, sessions, session time and first session to last, this week and last, at the studio the iPad is in. Not a timesheet |
| My clients | On your own My Profile, right after the Kaizen Roster: the clients you have trained most in Journey, coached lately first |
| 90-day check-in | The subjective progress report: 8 categories scored Green / Yellow / Red |
| Learning | The Catalog (machines) and the Academy (method), in one tab |
| Limbo | Mindbody events the app couldn't match to a studio, waiting for an admin |
| Operations Dashboard | The studio-leader dashboard (called the Admin Dashboard before Sep 2026) |

## InBody (270S)

| Term | Meaning |
| --- | --- |
| SMM | Skeletal muscle mass, in pounds |
| PBF | Percent body fat |
| BMR | Basal metabolic rate, in kcal per day |
| SMI | Skeletal muscle index: arm and leg lean mass divided by height squared |
| Phase angle | A whole-body reading at 50 kHz, tracked over time |
| Segmental lean | Lean mass for each arm, each leg and the trunk |

| Location | A studio inside a site |
| Contract | An agreement billed on a schedule (autopay) |
