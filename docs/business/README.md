# How Max Strength Fitness works — the business side

The code shows what the app does. These pages record what the business needs it to do: the rules nobody can read out of the source. Every page says where its facts came from and when.

| Page | Read it before working on |
| --- | --- |
| [packages-and-pricing.md](packages-and-pricing.md) | Anything that shows a package, a price, sessions remaining or a renewal |
| [renewals.md](renewals.md) | The Operations Dashboard, renewals, retention, anything that flags a client |
| [roles-and-permissions.md](roles-and-permissions.md) | Anything a trainer and a studio leader should see differently |
| [data-sources.md](data-sources.md) | Anything that reads Mindbody, FileMaker or InBody data, or decides which source wins |
| [glossary.md](glossary.md) | Any wording on screen — the studios have their own vocabulary |

**Keeping these true:** when a business rule changes, edit the page and add the date and who said so. A page that quietly goes stale is worse than no page, because it gets trusted.
