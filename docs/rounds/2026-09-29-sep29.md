## Names wrap (the once-over)

A read-only audit over `src/` found about forty-five places a name or a header could be cut off; the Operations shell, My Studio, the codex, the Directory's name column and the Hub cards were already clean. The sixteen real cut-offs of a PERSON'S or a MACHINE'S name were fixed (four commits on `names-wrap`): the top strip's studio name (ellipsised at 14 characters on a phone), the live session bar's client name and the Now Bar's machine names (54px and 46px rows now `min-height`), the routine-order sheet, the end-of-session list, the Routine Builder's names, the calendar's blocks, lanes and board, history's trainer and machine names, My Profile's five client lists, the staff editor's names, the performance dialog's machine name, a preset name, the chart grid's machine chip, the sign-in request's display name, the profile's sub-tab labels (the comment said wrap, the CSS clipped) and the Next strip's "with {trainer}". Each now wraps (`overflow-wrap: anywhere`), and `src/lib/names-wrap.test.ts` fails if any of them regains an ellipsis, a clamp, or nowrap with hidden overflow. Accepted and left: note bodies clamped to two lines, meta lines, the bottom bar's 9px tab labels, and Relay's first-name voice ("From Sam").
