## Built

1. **`bd73120f` Machine format v2 (Codex R2).** Optional fields on `MachineDefinition` (`types/machines.ts`, "THE CODEX FORMAT, v2"): the twelve leaves (`stopRules`, `watchOuts`, `setUp`, `dialRules`, `getSet`, `begin`, `rep`, `finish`, `ifWrong`, `adapt`, `program`, `faults`, `understand`; leaf 12 is computed), `switches` (`lowerTurn`, `repCap`, `tscCapable`, `unloadTransfer`; the other three are read from `requiresHandoff`, the upper turnaround's style and `neverToFailure`), each dial's `letter` and `callout` (unit) and rule (`dialRules[key]`, method), `sources` (per method line: `academy` · `guide` · `book`, paraphrased · `unsourced`, with `conflict`) and `modelId`. Nothing renamed; ids and dial keys unchanged; an old definition gains no key (`codexFieldsOf`). `features/machine-codex/format.ts` is the one reader. Object leaves merge per key on a copy; `stopRules`/`watchOuts` are additive. The editor reads and writes all of it in four optional sections (no gaps, so completeness and the catalog gate are unchanged).
2. **`418b168c` The model record.** `machineModels/{modelId}` = exactly `{ brand, model, movementId, dials?, notes?, updatedAt, updatedBy }` (`MachineModel`). Administrators write it whole; everyone signed in reads; never deleted; id minted once (`mm-…`). Admins → Catalog → **Models**, and a catalog machine's Models button. A roster entry names its unit's model (`modelId`, "Which model this unit is"); a copy never takes the catalog's reference model. **The app works with no model documents at all**: the picker offers "Not recorded", the page says none are recorded, a refused read says it couldn't read.
3. **`6ae0b6f9` The Sep 21 rule, with Compare.** A studio may change anything on its own copy; one of Max Strength's safety lines comes off only with a reason (3–300 characters, at most 10 per machine), recorded as `overrides.removedSafety: [{ field, line, reason, by: { uid, name }, at }]`, refused without one by `scopeOverrides` and the rules. **Compare** (a catalog machine's Compare button): every studio's differences, removed lines first with reason, who and when; settings and words only.
