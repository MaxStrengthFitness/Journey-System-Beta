# The injury map — questions for head office (saved for later)

AJ, Oct 7 2026: "make a document that makes this easy to answer but we will
save this for later." It belongs to the parked injury layer in
`2026-10-07-first-session-and-routines.md` §5.4: while a client has an open
Health or Incident note on a body part, the routine flags the machines that
matter for it. **Nothing changes by itself**; the flag only tells the trainer
to look ("doesn't mean we're completely avoiding it. Sometimes we might just
digress it").

**How to answer.** For each body part, each machine has Journey's guess and
where it came from. Write **Yes** (flag it), **No** (don't), or a word
("only for surgery"), in the Answer column. Add any machine that's missing.
The last column is what the Academy already says to do instead, which the
flag would offer.

Sources are short names for files in `docs/msf-academy/`: PAIN = Academy 6
`Considerations for Training with Pain`; CEO = `Initial Setups\Comprehensive
Equipment Overview\<machine>`; EST = Academy 6 `Programming and Progression 7`;
A4-10 = Academy 4 `Warm-up Considerations`.
